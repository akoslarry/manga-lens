# MangaLens - 漫画实时翻译器

> 一款 Chrome 浏览器扩展，实时识别并翻译漫画图片中的日文文字，支持 PDF 导出

## 功能特性

### 核心翻译管线

| 功能 | 说明 |
|------|------|
| **腾讯云 OCR** | 支持通用印刷体、高精度版、手写体、英文四种识别模式 |
| **DeepSeek V4 Pro 翻译** | 智能日→中翻译，上下文感知 |
| **并发控制** | OCR 队列（3并发）+ 翻译队列（5并发），10 任务上限自动暂停 |
| **对话合并** | 基于距离聚类的智能分组算法，竖排/横排自适应方向检测 |
| **四角锚点** | 8 点锚点自动检测图片旋转并校正坐标 |
| **RTL 支持** | 日漫从右往左阅读模式 |
| **本地翻译缓存** | IndexedDB 持久化存储，刷新页面无需重新调用 API，节省 Token |

### PDF 导出编辑

| 功能 | 说明 |
|------|------|
| **字体自适应** | 按气泡尺寸与字数自动计算字号（算法 v1，见下文） |
| **溢出视觉提示** | 译文超出气泡时显示橙色角标与描边，提示手动调整 |
| **进入导出模式** | Popup 一键进入编辑态 |
| **双击编辑文字** | 双击覆盖层直接修改翻译文本 |
| **拖拽移动** | 拖拽覆盖层调整位置 |
| **缩放手柄** | 四角拖拽调整覆盖层尺寸 |
| **字号调节** | 单个覆盖层独立字号设置 |
| **透明度控制** | 独立调节覆盖层透明度 |
| **删除覆盖层** | 移除不需要的翻译气泡 |
| **工具栏** | 选中覆盖层弹出编辑工具栏（字号/透明/删除） |
| **PDF 导出** | jsPDF + html2canvas 合成 PDF，支持自定义保存子目录 |
| **退出自动保存** | 退出时自动持久化所有编辑到本地缓存 |

## 核心模块说明

### 1. content-script.ts — 内容脚本主入口

漫画页面的图片检测、OCR 排队、翻译渲染、PDF 编辑模式的全部调度中心。

**并发控制机制**:

```
OCR 队列: 3 并发
翻译队列: 5 并发
任务上限: 10（队列满时暂停 OCR）
批次上限: 默认 30 张/次（可在 Popup 中配置 1-100）
```

**消息类型**:

| 消息 | 来源 | 功能 |
|------|------|------|
| `TOGGLE_ENABLED` | Popup | 开关翻译 |
| `CONFIGURE_API` | Popup | 更新 API 配置 |
| `REFRESH` | Popup | 刷新页面翻译 |
| `SELECT_IMAGE` | Popup | 手动选择图片 |
| `GET_STATUS` | Popup | 获取处理状态 |
| `ENTER_PDF_MODE` | Popup | 进入 PDF 导出编辑模式 |

### 2. background.ts — Service Worker

API 请求中转，解决浏览器跨域限制。核心能力：图片 URL→Base64 转换、腾讯云 OCR 签名请求（Base64 及 URL 两种模式）。

### 3. dialog-merger.ts — 对话合并

距离聚类算法将 OCR 碎片合并为完整对话。

**合并流程**：预处理（边界计算 + 竖排/横排判断）→ 分离方向 → 按行/列分组 → 组内排序（竖排按Y、横排按 RTL 规则）→ 距离阈值合并。

### 4. translation-cache.ts — 本地翻译缓存

基于 IndexedDB 的持久化翻译缓存。刷新页面时直接读取缓存渲染，避免重复调用 OCR/翻译 API。在 PDF 编辑模式下自动同步用户修改（文字/位置/字号/透明度/删除）。

### 5. export-pdf.ts — PDF 导出编辑引擎

完整的所见即所得编辑系统：

- **选择系统**：点击选中覆盖层，边框高亮 + 缩放四角手柄
- **文本编辑**：双击覆盖层进入文字编辑模式
- **拖拽移动**：选中后拖拽平移覆盖层位置
- **缩放手柄**：四角拖拽缩放覆盖层尺寸
- **工具栏**：选中后弹出浮动工具栏（字号调节/透明度滑块/删除按钮）
- **PDF 合成**：jsPDF + html2canvas 渲染整页为 PDF
- **自动保存**：退出时自动持久化所有编辑到 IndexedDB 缓存

### 6. ocr-engine.ts — OCR 引擎

腾讯云 OCR 调用与四角锚点机制。在图片四角及四边中点添加 8 个锚点标记，OCR 识别锚点后对比预期位置检测旋转角度，校正所有文字坐标。

### 7. font-fitter.ts — 字体自适应计算（算法 v1）

解决「大框小字」「小框溢出」两类问题，同时保留原文的视觉分级。

**设计目标**：
- 超大气泡 + 少数字（标题/拟声词）→ 字号应足够大，填满空间
- 超小气泡 + 大量文字（小字说明）→ 优先保证不溢出，但不得低于可读下限
- 保留原文的相对大小对比（拟声词大、说明文字小），不因翻译而抹平

**四步计算流程**：

| 步骤 | 说明 |
|------|------|
| **1. 几何适配** | 由框宽高与译文字符数解析求解「刚好填满」的字号。按字符组成估算平均宽度比（全角≈1、半角≈0.55），用二分法逼近满足 `行数 × 字号 × lineHeight ≤ 可用高度` 的最大字号 |
| **2. 视觉分级** | 取 OCR 得到的原文实际字符高度（竖排取片段宽度、横排取片段高度的中位数），与几何解加权融合（默认原文权重 0.6），避免拟声词被撑爆、小字说明喧宾夺主 |
| **3. 约束** | 施加 `fillRatio`（默认 0.88，留呼吸空间）与 `[minFontSize, maxFontSize]` 区间。字号不得低于可读下限 |
| **4. 迭代收敛** | 元素入 DOM 后，以浏览器真实排版为权威，测量 `scrollHeight` vs `clientHeight`，按 0.9 / 1.06 系数迭代修正（最多 6 次），解决中英混排、标点避头尾、字体度量等公式算不准的问题 |

**溢出处理策略**（重要设计决策）：

> **不自动扩大文本框。** 自动扩框会让用户失去原始位置参考，且粗略阅读时必须进入编辑模式才能重新看到画面。因此采用**视觉提示**：溢出时给覆盖层加橙色描边 + 右上角 `⤢` 角标 + tooltip 说明，由用户决定是否手动调整。

**溢出提示与 PDF 编辑模式的关系**：

- 角标与描边均为 `pointer-events: none`，是**纯视觉标记**，不具备点击功能；非编辑模式下覆盖层本身也不接收事件（点击穿透到原画），因此不会误触
- 描边用 `box-shadow` 而非 `outline` 实现，以避免与编辑态的蓝色选中 `outline`（`2px solid #667eea`）互相覆盖，也避免退出编辑时被清空
- **人工调整即撤下**：在 PDF 模式下拖拽缩放或移动文本框后，**直接撤下溢出提示，不做复检**
  - 设计理由：用户手动调整代表其已知意图，系统无需再评判结果。若复检，则「故意缩小文本框」的场景下标记将永远无法消除，与用户意图对抗
  - 被人工调整过的对话会记入内部集合，后续重新渲染也不再为其添加溢出标记

**与字体缩放的协同**：

- 每个覆盖层自适应算出的字号记为该覆盖层的「基准字号」（缓存在内存 Map 中）
- 角标上的 `−` / `+` 缩放按钮作用于「基准字号 × 缩放系数」，因此放大缩小时**各气泡仍保持自身的相对大小**，视觉分级不丢失
- popup 的「默认字体大小」配置语义变为「整体调整基准」（以 22px 为 1.0 系数），不再直接作为字号

**版本号与缓存迁移**：

`MergedDialog.fontSizeVersion` 记录该条目使用的算法版本（当前 `FONT_SIZE_ALGO_VERSION = 1`）。读取本地缓存时：
- 若版本缺失或低于当前版本 → 触发**自动迁移**：更新版本标记并回写缓存
- 字号本身不持久化（渲染时实时计算），因此迁移无需改动对话数据，用户的手动调整（`customFontSize` 等）会被完整保留

版本历史：

| 版本 | 算法 |
|------|------|
| 0 / 缺失 | 旧算法：仅按「译文字数 / 原文字数」比例缩放，不感知框尺寸 |
| 1 | 几何适配 + 视觉分级 + 迭代收敛 + 溢出检测 |

## 使用方法

### 基础操作

1. **配置 API**：点击扩展图标 → 分别配置翻译 API 和 OCR 设置 → 保存并测试连接
2. **开启翻译**：打开右上角开关，页面自动开始处理漫画图片
3. **手动选择**：点击"手动选择图片或重新翻译" → 点击页面上的目标图片
4. **刷新翻译**：点击"刷新页面翻译"按钮

### PDF 导出流程

1. 等待所有目标图片翻译完成
2. 点击 Popup 中的「进入PDF导出模式」
3. 在编辑模式下调整覆盖层：双击改文字、拖拽改位置、缩放改大小、工具栏调字号/透明度
4. **随时点工具栏「💾 保存」**：立即持久化改动到本地缓存，且**停留在编辑模式**继续调整
5. 点击「❌ 退出」：若无未保存改动则直接退出；若有则弹窗询问「保存 / 恢复」
6. 下一次进入同一页面时，编辑结果会从缓存直接加载

> 编辑文字时使用 `Ctrl+V` 粘贴会自动剥离源格式（只保留纯文本），确保文本框内字号统一。

## 常见问题

**Q: OCR 识别不准确？**
检查图片清晰度，漫画推荐使用「高精度识别」模式。锚点机制会自动检测和校正旋转。

**Q: 翻译很慢？**
检查网络连接和 API 配额。翻译瓶颈通常在 DeepSeek API 响应速度，OCR 3 并发可充分并行。

**Q: 如何卸载扩展？**
打开 `chrome://extensions/`，找到 MangaLens，点击"移除"。

**Q: 退出 PDF 模式后编辑丢失？**
v1.1.0 起退出时自动弹窗确认并持久化。选择"保留修改"即写入本地缓存，刷新页面不丢失。

## 更新日志

### v1.4.0

**PDF 导出三项修复**

- **新增「💾 保存」按钮**：位于工具栏「退出」左侧，点击即持久化当前所有修改到本地缓存，**不退出** PDF 编辑模式，按钮短暂显示「✅ 已保存」反馈
  - 修复隐藏缺陷：双击编辑文字时原先**没有 `input` 监听**，纯文字修改不会置 `pdfModeEditDirty`，导致退出前的静默保存被跳过（存在丢修改风险）。现已补齐
  - 退出弹窗条件优化：保存后**无新修改**时点「退出」直接退出不弹窗；保存后**又有修改**时才正常弹窗
- **文字编辑统一字号**：双击编辑时拦截粘贴事件，强制纯文本粘贴（`text/plain` + `execCommand('insertText')`），并对内容做规范化——移除所有富文本标记，只保留纯文本与 `<br>` 换行
  - 修复现象：从 22px 文本框复制到 20px 文本框时，源内联 `font-size` 会覆盖当前字号，导致同一框内出现两种字号
- **图片适配修复**：拖入浏览器的图片（blob: URL）此前导出为空白
  - `blob:` URL 改在 content-script 侧 `fetch` 后转 dataURL（background 无法访问页面创建的 blob）
  - `isSameOrigin` 现排除 `blob:`/`file:`，同源图片也统一转 dataURL，规避 canvas 污染
  - 绘制后主动探测 canvas 污染，提前抛出明确错误而非静默空白
  - 导出失败**如实告知**：列出失败页序号与原因（原先仅 `console.error` 静默跳过）
  - PDF 文字绘制改用 `dataset.mlPlainText`，避免溢出角标 `⤢` 被画进 PDF

### v1.3.0

- **字体自适应算法 v1**：字号不再使用固定值，改为按气泡尺寸与译文字数自动计算，解决「超大文本框只装几个字字号偏小」「超小文本框文字溢出」两类问题
  - 几何适配：由框宽高与字符数解析求解理想字号
  - 视觉分级：参考原文实际字符高度，保留原文大小对比（拟声词大、小字说明小）
  - 迭代收敛：以浏览器真实排版为准测量精修，解决中英混排与标点避头尾偏差
- **溢出视觉提示**：译文超出气泡范围时显示橙色描边 + `⤢` 角标 + tooltip，不自动扩大文本框（避免用户失去原始位置参考）
  - 角标为纯视觉标记（`pointer-events: none`），与文本框缩放手柄互不干扰
  - 描边改用 `box-shadow` 实现，避免与 PDF 编辑态的蓝色 `outline` 冲突
  - 人工调整尺寸/位置后**无条件撤下提示**（尊重用户意图，不做复检），且后续渲染不再重复标记
- **字号可读下限**：自适应计算不得低于 10px，宁可溢出也不牺牲可读性
- **字体缩放协同**：缩放按钮与「默认字体大小」作用于各气泡的基准字号，保持相对大小关系，视觉分级不丢失
- **缓存版本迁移**：新增 `fontSizeVersion` 字段，读取旧缓存时自动升级算法版本并回写，用户手动调整不受影响
- **翻译模型升级**：切换至 DeepSeek V4.1 Flash（API 模型 ID `deepseek-flash`）
